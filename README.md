# 📚 Knowledge Base UI (Frontend Assignment)

## 🚀 Overview
This project is a React-based implementation of a Knowledge Base UI, built by replicating a Figma design with high visual accuracy. It demonstrates component-based architecture, clean UI design, and basic user interactions.

---

## 🛠️ Tech Stack
- React (Functional Components + Hooks)
- Tailwind CSS
- JavaScript (ES6+)

---

## ✨ Features

### 📌 UI Implementation
- Pixel-accurate Knowledge Base layout
- Clean typography, spacing, and alignment
- Responsive grid-based card layout

### 📌 Core Functionality
- View knowledge base cards
- Create new entry using **right-side drawer**
- Edit & delete existing entries
- Pagination controls
- Dynamic **Rows per page** selection

### 📌 Components Used
- Header
- Sidebar (static)
- Card
- Button
- Drawer (custom implementation)
- Form inputs
